UPGRADE NOTE (breaking): the executor runs as the StatefulSet {{ $fullname }}-executor.

  cannot convert. When upgrading from such a release, delete the old Deployment first:
    kubectl delete deployment {{ $fullname }}-executor -n {{ .Release.Namespace }}
  then run helm upgrade again. The value executor.strategy was renamed to
  executor.updateStrategy (type RollingUpdate or OnDelete, no maxSurge).
